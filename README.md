# بيتنا أخضر.. وقطر مستدامة

مسابقة فيديو قصير ضمن أسبوع قطر للاستدامة
مدرسة هند بنت عتبة الإعدادية للبنات - قسم الحوسبة وتكنولوجيا المعلومات

## محتويات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | صفحة المسابقة (تُنشر على Vercel) |
| `config.js` | رابط السكريبت الذي يستقبل الفيديو |
| `poster.jpg` | ملصق المسابقة |
| `vercel.json` | إعدادات Vercel |
| `Code.gs` | كود Google Apps Script (يُلصق في script.google.com، وليس جزءًا من الموقع) |

## طريقة العمل

1. ولي الأمر يفتح الموقع على Vercel ويملأ النموذج ويختار الفيديو.
2. الصفحة ترسل الفيديو إلى Google Apps Script.
3. السكريبت يحفظ الفيديو في مجلد Google Drive، ويسجل المشاركة في جدول «سجل المشاركات».

مجلد Drive يبقى خاصًا، ولا يستطيع أولياء الأمور فتحه.
